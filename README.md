# 경기예술인의집 나들이 · 김윤신 작가 나들이

- **일시**: 2026년 11월 26일(목) 오후 1시 ~ 2시
- **장소**: 경기도 파주시 문발로 123

## 파일

| 파일 | 내용 |
| --- | --- |
| `poster.html` | A4 세로 포스터. 브라우저로 열어 인쇄(여백 없음)하거나 PDF로 저장 |
| `google-form.gs` | 참가 신청 구글폼 + 응답 시트를 한 번에 만드는 Apps Script |
| `README.md` | 사용법과 홍보 문구 |

## 순서

1. https://script.google.com → 새 프로젝트 → `google-form.gs` 내용 붙여 넣기 → `createOutingForm` 실행
2. 실행 로그의 **응답 링크**를 복사
3. `poster.html` 안의 `const FORM_URL = "";` 따옴표 사이에 붙여 넣기 → QR코드 자동 생성
4. 포스터 인쇄 / 이미지 저장, 아래 홍보 문구와 함께 배포
